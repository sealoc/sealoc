# SEALOC

SEALOC is a benchmark dataset and Python library for long-term visual localization in
dynamic benthic (underwater) environments. The library provides tools for downloading
the dataset and querying camera geometry data (poses, footprints, calibrations).

- [Getting started](getting-started.md): install, download the dataset, and run your first query
- [Usage](usage.md): practical examples for querying bundles, calibrations, poses, and spatial indices
- [Data model](data-model.md): bundles, groups, cameras, poses, and footprints explained
- [API reference](api/dal.md): reference generated from the source code docstrings

The dataset is available at [doi:10.11582/2026.QRO1LF3Z](https://doi.org/10.11582/2026.QRO1LF3Z),
and the accompanying paper at [doi:10.3389/frobt.2026.1821019](https://doi.org/10.3389/frobt.2026.1821019).
